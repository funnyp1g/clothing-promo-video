# Bundled font sources

- Noto Sans SC Regular/Bold: existing project font assets, SIL OFL (OFL.txt).
- Source Han Serif CN Regular: Adobe Source Han Serif release, SubsetOTF/CN/SourceHanSerifCN-Regular.otf. https://github.com/adobe-fonts/source-han-serif/tree/release/SubsetOTF/CN . Unmodified font, SIL OFL, see SourceHanSerif-LICENSE.txt.

The standalone runner checks that both serif and sans fonts can be loaded. These fonts are bundled; rendering does not depend on operating-system-only fonts.
